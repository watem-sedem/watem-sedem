DistributeRiver_Routing

Routing for river cells only.

Previous file: Calculate_routing overview. Next file: DistributeTilDirEvent_Routing. 
flowchart TD
    A[Start DistributeRiver_Routing for river cell i,j] --> B[Read current river segment from RivSeg i,j]
    B --> C[Initialize OK as false and clear rowmin and colmin]
    C --> D{Does river_routing_map contain an explicit direction for this cell?}
    D -- Yes --> E[Call Follow_Direction using river_routing_map]
    E --> F[Set OK to true]
    F --> G[Return with one explicit target]

    D -- No --> H[Read nextsegment from river_adjectant for the current segment]
    H --> I{Is nextsegment equal to 0?}
    I -- Yes --> J[Exit without assigning a downstream segment target]
    I -- No --> K[Start outward search with kernel size W = 1]
    K --> L[Inspect only the outer ring of the current search window]
    L --> M{Does the search ring contain a cell whose RivSeg equals nextsegment?}
    M -- Yes --> N[Store row and column offset as ROWMIN and COLMIN]
    N --> O[Mark check as true]
    O --> P{Did we find a valid downstream segment cell?}
    M -- No --> Q[Increase the kernel size]
    Q --> R{Has W become larger than max_kernel?}
    R -- No --> K
    R -- Yes --> S[Mark this river cell as having no valid target]
    S --> T[Set One_Target to false]
    T --> U[Set Target1 to invalid coordinates]
    U --> V[Set Part1 to 0]
    V --> W[Exit]

    P -- Yes --> X{Is rowmin or colmin different from 0?}
    X -- Yes --> Y[Assign Target1 to i + ROWMIN and j + COLMIN]
    Y --> Z[Set One_Target to true]
    Z --> AA[Set Part1 to 1.0]
    AA --> AB[End river routing for this cell]
    X -- No --> AC[End without further assignment]
