Calculate_routing overview

This page shows only the top-level orchestration in Calculate_routing.

Next files to open from this page: DistributeRiver_Routing, DistributeTilDirEvent_Routing, then FindLower, and finally Apply_Routing.
Important: the `DistributeTilDirEvent_Routing` branch is internally split into two phases. First there is an early-exit phase for buffers, ditches, dams, nearby rivers, and nearby ditch or dam routing. Only if none of those cases applies does the code continue into the candidate-target phase, where two targets are chosen and filtered using elevation, parcel, and grass-strip rules. 
flowchart TD
    A[Start Calculate_routing] --> B[Allocate Routing array with one record per raster cell]
    B --> C[Initialize each cell with invalid targets and zero parts]
    C --> D[Loop over all rows]
    D --> E[Loop over all columns]
    E --> F{Is the cell outside the study area?}
    F -- Yes --> G[Skip the cell]
    G --> H{More cells left?}
    F -- No --> I{Is the cell a river cell?}
    I -- Yes --> J{Is river_routing enabled?}
    J -- Yes --> K[Call DistributeRiver_Routing for this cell]
    J -- No --> L[Do nothing for this river cell here]
    I -- No --> M[Call DistributeTilDirEvent_Routing for this cell]
    K --> H
    L --> H
    M --> H
    H -- Yes --> E
    H -- No --> N{Is force_routing enabled?}
    N -- No --> O[Call Apply_Routing]
    N -- Yes --> P[Loop over forced_routing definitions]
    P --> Q[Overwrite Target1 with the forced target cell]
    Q --> R[Set Target2 invalid, Part1 to 1, Part2 to 0, One_Target to True]
    R --> S{More forced routes left?}
    S -- Yes --> P
    S -- No --> O
    O --> T[Invert routing and build processing order]
    T --> U[End Calculate_routing]
