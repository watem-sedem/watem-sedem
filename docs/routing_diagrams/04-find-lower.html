FindLower

Fallback routing when no valid local routing target remains.

Previous file: DistributeTilDirEvent_Routing. Next file: Apply_Routing. 
flowchart TD
    A[Start FindLower for cell i,j] --> B[Initialize search window W = 1]
    B --> C[Clear best same-parcel, river, and different-parcel candidates]
    C --> D[Inspect only the outer ring of the current search window]
    D --> E{Is there a lower same-parcel candidate?
Also true for source parcel -> grass strip}
    E -- Yes --> F[Store the lowest lower same-parcel cell]
    F --> G[Mark check_sameparcel as true]
    G --> H{Is there also a river candidate or a different-parcel candidate?}
    H -- Any --> I[Same-parcel candidate still has priority]

    E -- No --> J{Is there a river cell in the search window?}
    J -- Yes --> K[Store the lowest river cell]
    K --> L[Mark check_river as true]

    J -- No --> M{Is there a lower cell in a different parcel?}
    M -- Yes --> N[Store the lowest lower different-parcel cell]
    N --> O[Mark check_differentparcel as true]
    M -- No --> P[No valid candidate found in this window]

    I --> Q{Any valid candidate found?}
    L --> Q
    O --> Q
    P --> Q

    Q -- No --> R[Increase W]
    R --> S{Is W greater than max_kernel?}
    S -- No --> D
    S -- Yes --> T[Mark the cell as having no valid fallback target]
    T --> U[Set all targets and parts to invalid values]
    U --> V[Return False]

    Q -- Yes --> W{Was a same-parcel candidate found?}
    W -- Yes --> X[Assign the same-parcel or parcel-to-grass candidate as Target1]
    W -- No --> Y[Assign the river or different-parcel candidate as Target1]
    X --> Z[Set One_Target to True, Part1 to 1, Part2 to 0]
    Y --> Z
    Z --> AA[Return True]
