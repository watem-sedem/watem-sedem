Routing Diagrams (Updated Routing Logic)

These pages split the routing logic from Raster_calculations.pas into smaller readable diagrams. This copy reflects the updated simplified Part B and adjusted FindLower parcel-to-grass behavior. Open them separately in a browser so the Mermaid graphs stay legible.

Recommended reading order: overview -> river routing -> land routing -> FindLower -> Apply_Routing

1. Calculate_routing overview

Top-level flow: initialize routing table, choose river versus non-river routing, apply forced routing, then finalize with Apply_Routing.

overview

2. DistributeRiver_Routing

Decision flow for river cells: explicit river direction, downstream segment search, and fallback when no next segment cell can be found.

river routing

3. DistributeTilDirEvent_Routing

Main routing logic for non-river cells: buffers, ditches, dams, rivers nearby, tillage versus aspect direction, and the two-target parcel checks.

land routing

4. FindLower

Fallback behavior when no valid local target remains and the search expands outward for a lower or acceptable target.

fallback

5. Apply_Routing

Post-processing of the routing table: inversion, queue construction, and optional reporting of unresolved routes.

finalization
