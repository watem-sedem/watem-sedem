DistributeTilDirEvent_Routing

This page splits the non-river routing logic into a preparation phase and a detailed candidate-target decision phase.

Previous file: DistributeRiver_Routing. Next file: FindLower, then Apply_Routing.
When is Part A used? Part A is always entered first for a non-river cell. It handles the early-exit cases: buffers, ditches, dams, cells directly routing into a nearby river, and cells directly routing into a nearby ditch or dam.
When is Part B used? Part B is only reached if none of those early-exit cases applied. In that case Part A computes a flow direction, chooses two candidate target cells, and then passes control to Part B.
So the rule is: if Part A exits early, Part B is skipped completely. If Part A reaches the node Continue to detailed parcel and elevation decision logic, then Part B is applied.
Part A: early-exit and direction setup

Part A: special cases and direction choice

Part A ends immediately for buffer, ditch, dam, nearby-river, and nearby-ditch-or-dam cases. Only the bottom branch of this diagram continues into Part B.

flowchart TD
    A[Start DistributeTilDirEvent_Routing for non-river cell i,j] --> B{Is the cell part of a buffer?}
    B -- Yes --> C[Call Apply_Buffer]
    C --> D[Buffer logic assigns one target and exits]

    B -- No --> E{Is the cell part of a ditch?}
    E -- Yes --> F[Call Follow_Direction using ditch_map]
    F --> G[Assign one ditch target and exit]

    E -- No --> H{Is the cell part of a dam?}
    H -- Yes --> I[Call Follow_Direction using dam_map]
    I --> J[Assign one dam target and exit]

    H -- No --> K[Inspect the 3x3 neighborhood around the cell]
    K --> L{Is there an adjacent river cell that may be used under the cardinal routing rule?}
    L -- Yes --> M[Choose the lowest allowed river neighbor]
    M --> N[Assign that river cell as Target1]
    N --> O[Set Part1 to 1.0 and exit]

    L -- No --> P{Is there an adjacent ditch or dam cell?}
    P -- Yes --> Q[Choose the lowest adjacent ditch or dam cell]
    Q --> R[Assign that ditch or dam cell as Target1]
    R --> S[Set Part1 to 1.0 and exit]

    P -- No --> T{Use tillage direction instead of aspect?}
    T -- Yes --> U[Use tillage direction]
    U --> V[If needed, reverse it so it points downslope]
    V --> W[Continue with this direction]

    T -- No --> X[Use aspect direction]
    X --> W[Continue with this direction]

    W --> Y[Compute CSN and SN]
    Y --> Z[Determine the quadrant of the direction]
    Z --> AA[Select candidate Target1 and Target2 in that quadrant]
    AA --> AB[Initialize Part1 and Part2 from the directional split]
    AB --> AC[Continue to detailed parcel and elevation decision logic]

Part B: candidate-target filtering

Part B: simplified candidate target filtering

Part B starts only after Part A has already chosen two candidate targets from the flow direction. It keeps the split only when both targets are downslope and land-cover compatible; otherwise it falls back to FindLower.

    flowchart TD
    A[Two candidate targets already chosen] --> B{Is Target1 or Target2 higher than the source cell?}
    B -- Yes --> C[Set Part1 to 0 and Part2 to 0]
    B -- No --> D{Are both targets land-cover compatible with the source?}
    D -- Yes --> E[Keep Part1 and Part2 from the directional split]
    D -- No --> C

    C --> F{Are both Part1 and Part2 equal to 0 now?}
    E --> G[Write the chosen target information into Routing]
    F -- Yes --> H[Call FindLower fallback]
    F -- No --> G
    G --> I[If Part1 is 0, clear Target1]
    I --> J[If Part2 is 0, clear Target2]
    J --> K[Return to Calculate_routing]
    H --> K

    D -. rule .-> R1[For each target: same parcel as source OR grass strip when source is a parcel]
